# موقع مؤسسة وقت الديار للمقاولات

موقع ويب صفحة واحدة (One Page) باللغة العربية، متجاوب مع الجوال والكمبيوتر.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفعه على أي استضافة تدعم المواقع الثابتة.

## تعديل البيانات
كل المحتوى موجود في `index.html` ويمكن تعديل النصوص والصور والبيانات لاحقًا.
الصور والشعار داخل مجلد `assets`.
